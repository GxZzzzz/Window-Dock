# 图标资源

正式资源位于 `assets/icons/ios-category-v2/`。目录名保留现有加载接口，资源版本由 `manifest.json` 的 `version` 表示，当前为 **v3**。

- 16 张 512 × 512 RGBA PNG，内嵌 sRGB 色彩配置，透明背景。
- 分类入口包含 IDE、办公、工控、娱乐、工具、文档、图片、文件夹、压缩包、影音、其他、应用和收藏。
- 系统入口包含此电脑、空回收站和满回收站。
- `work` 复用 `office`；`code` 复用 `ide`。
- 分类内的软件图标来自 Windows，不替换各软件自己的图标。

## 替换

先退出 Dock，备份现有资源。按 manifest 中的键和相对路径替换 PNG，重启生效。

源码模式读取仓库中的资源目录。打包后优先读取 EXE 旁的同名外部目录；没有外部目录时使用 `_internal` 中随包携带的资源。外部目录需要是一套完整资源包。单项加载失败会走已有绘制回退。

`icon_theme.py` 按需加载并缓存缩放结果，没有资源目录监听或定时刷新。添加新的图标键还需同步分类编辑器里的可选图标，单独增加图片不会自动新增 UI 选项。

## 来源

这套图标通过本地 ComfyUI / SDXL 工作流辅助生成并整理为静态资源，具有统一圆角、配色和微立体风格。它们不是 Apple 官方图标，也不包含分类内第三方应用的品牌图标。

模型、生成服务、候选图、生成日志和本机工作流不参与程序运行，也不随源码分发。已发布 PNG 作为本项目资源按仓库许可证提供；所用工具、模型及依赖各有自己的许可，不随本项目改为 MIT。
